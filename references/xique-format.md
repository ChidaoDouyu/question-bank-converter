# 喜鹊刷题 CSV 格式说明

## 列定义

| 列 | 字段 | 说明 |
|----|------|------|
| A | 题干 | 题目内容 |
| B | 题型 | `单选题` / `多选题` / `判断题` / `简答题` |
| C~J | 选项 A~H | 选项文本 |
| K | 正确答案 | 见下方规则 |
| L~S | *(留空)* | 8 列留空，不得填写任何内容 |

## 正确答案填写规则

| 题型 | K 列填写方式 |
|------|-------------|
| **单选题** | 填正确选项字母，如 `C` |
| **多选题** | 填正确选项字母连写，如 `BD`，不用分隔符 |
| **判断题** | C 列填 `对`，D 列填 `错`，K 列填 `A`（对）或 `B`（错） |
| **简答题** | C~J 留空，K 列填答案文本 |

## 编码说明

CSV 文件需使用 **GBK** 编码导入喜鹊刷题。

`step2_xique.py` 脚本已内置编码转换。若出现乱码，可手动执行：

```python
content = open('输出.csv', encoding='utf-8').read()
open('输出.csv', 'w', encoding='gbk').write(content)
```
